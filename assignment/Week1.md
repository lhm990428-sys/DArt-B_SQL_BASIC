# 3️⃣ 확인 문제

## 🧩 문제 1

포켓몬 게임이나 이커머스 산업과 같이 다양한 산업에서는 각기 다른 데이터가 존재합니다. 다음 중 하나의 산업을 선택하고, 해당 산업에서 수집하고 활용될 수 있는 데이터 항목, 즉 컬럼 5가지를 자유롭게 상상하여 나열해주세요.

예시 산업:
- 온라인 음식 배달
- 스마트 헬스 케어
- 중고 거래 앱
- 교육 플랫폼

풀이 과정:

```
- 선택한 산업: 온라인 음식 배달
- 떠올린 컬럼 5가지: 주문자 ID, 주문 일시, 음식 종류, 주문 금액, 배송 소요 시간
- 해당 컬럼이 필요하다고 생각한 이유: 주문자별 이용 패턴, 시간대별 주문량, 선호 음식, 매출 규모, 평균 배달 시간 등을 분석하기 위해 필요함.
```

## 🧩 문제 2

이번 강의를 통해 SQL이 왜 필요하다고 느끼는지, SQL을 통해 본인이 어떤 것을 해내고 싶은지를 자유롭게 작성해주세요.

풀이 과정:

```
- SQL이 필요하다고 느낀 이유: 많은 데이터에서 필요한 정보를 빠르게 찾고 분석하기 위해 필요하다고 느꼈다.
- SQL로 해보고 싶은 일: 관심 도메인에 관한 데이터를 이용 및 수집하며 원하는 방향으로 SQL을 이용하여 데이터 분석을 해보고 싶다.
- 앞으로 SQL을 공부할 때 기대되는 점: 데이터를 직접 다루며 분석 역량을 높일 수 있을 것으로 기대한다.
```
