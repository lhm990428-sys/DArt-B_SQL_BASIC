## 01.

```
개념 이름: GROUP BY와 HAVING
개념 설명:
GROUP BY는 특정 컬럼을 기준으로 데이터를 그룹화하고,
HAVING은 그룹화된 결과에 조건을 적용한다.
WHERE은 그룹화 이전, HAVING은 그룹화 이후에 사용한다.
예시 쿼리:
SELECT type1, COUNT(*) AS pokemon_count
FROM basic.pokemon
GROUP BY type1
HAVING COUNT(*) >= 10;
```

## 02.

```
개념 이름: CASE WHEN
개념 설명:
조건에 따라 서로 다른 값을 반환하는 조건문이다.
WHEN으로 조건을 지정하고 THEN으로 결과를 설정한다.
ELSE는 모든 조건에 해당하지 않을 때 반환할 값이다.
예시 쿼리:
SELECT
    id,
    speed,
    CASE
        WHEN speed >= 100 THEN '매우 빠름'
        WHEN speed >= 70 THEN '빠름'
        ELSE '느림'
    END AS speed_category
FROM basic.pokemon;
```

## (선택) 03.

```
개념 이름:JOIN
개념 설명:
두 개 이상의 테이블을 공통된 컬럼을 기준으로
연결하여 데이터를 조회하는 기능이다.
아직 헷갈리는 점:
- 여러 테이블을 JOIN할 때 조인 순서와 조건에 따른 결과 차이
- LEFT JOIN 이후 WHERE 조건을 적용할 때 INNER JOIN과 유사한 결과가 발생하는 이유
```

## 🧩 문제 2

문제 링크: [동명 동물 수 찾기](https://school.programmers.co.kr/learn/courses/30/lessons/59041)

풀이 과정:

```
- 그룹화 기준: GROUP BY NAME — 동물의 이름을 기준으로 그룹화한다.
- 제외해야 하는 값:WHERE NAME IS NOT NULL — 이름이 없는 동물은 집계에서 제외한다.
- HAVING 조건:HAVING COUNT(*) >= 2 — 같은 이름이 2번 이상 사용된 경우만 조회한다.
- 복습한 점:WHERE은 그룹화 이전에 개별 행을 필터링하고, HAVING은 그룹화 이후 집계 결과에 조건을 적용한다. 또한 COUNT(*)로 그룹별 데이터 개수를 계산할 수 있다.
```
